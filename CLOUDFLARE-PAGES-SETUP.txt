YF TTS Studio Admin — Cloudflare Pages settings

Framework preset: Vite
Build command: npm run build
Build output directory: dist
Root directory: /

Environment variables:
VITE_SUPABASE_URL = https://YOUR_PROJECT_REF.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY = YOUR_SUPABASE_PUBLISHABLE_OR_ANON_KEY

Before deploying:
1. Run supabase/setup.sql in the existing Supabase project's SQL Editor.
2. Create your admin user in Supabase Authentication.
3. Follow supabase/ADMIN_SETUP.md to insert that user into public.admin_users.
4. Add the two environment variables in Cloudflare Pages > Settings > Environment variables.
5. Deploy.
